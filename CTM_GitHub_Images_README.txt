CTM COMMUNITY WEBSITE — GITHUB IMAGE SETUP

UPLOAD STRUCTURE
Keep index.html and the assets folder together in the repository root:

CTM-Community/
├── index.html
└── assets/
    ├── ctm-logo.png
    ├── praisegod.png
    └── ... (all remaining files listed below)

IMPORTANT
1. Rename each image file to EXACTLY match a filename below (including lowercase letters and extension). GitHub Pages filenames are case-sensitive.
2. Upload all these image files inside the folder named assets. Do not place them beside index.html.
3. Upload the provided HTML as index.html in the repository root.
4. The same logo file is used in both the header and footer: ctm-logo.png.
5. These are filenames the HTML expects. Actual image files are not included in this code package; you must upload your own matching images.
6. Keep the image roles matched to the labels below; do not swap screenshots/photos if you want each one in its intended section.

QUICK GITHUB STEPS
1. Create/open your GitHub repository.
2. Upload CTM_GitHub_Ready_index.html and rename it to index.html.
3. Create a folder named assets and upload every image using the exact filenames above.
4. In repository Settings → Pages, select your deployment source/branch if GitHub Pages is not already enabled.
5. Open the published site. If any image is missing, check the spelling, extension, folder name, and capitalization against this list.
